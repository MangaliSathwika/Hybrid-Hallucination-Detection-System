### 🔍 Project Overview
Large Language Models (LLMs) enable powerful context generation but are prone to factual fabrications known as hallucinations. This project presents an end-to-end post-hoc verification and correction tool designed to safeguard AI deployments against factual drift. 

By decoupling generation from verification, the system runs an automated evaluation layer that checks if claims generated by an agent are anchored faithfully in the provided reference materials.

### ⚙️ How it Works (The RAG Pipeline)
1. **Context Extraction & Chunking:** Reference source text data is parsed, broken down into semantic vectors, and stored in a searchable index database.
2. **Dynamic Query Interception:** When a user queries the LLM, the system generates the primary answer while concurrently querying the local vector store for highly relevant source evidence chunks.
3. **Hybrid Cross-Evaluation:** The system calculates semantic distance and structural consistency between the LLM’s text response and the retrieved ground-truth vectors.
4. **Streamlit UI Interface (`app.py`):** Visualizes the original response alongside highlighted text spans flagged for high-risk hallucination probabilities, returning a definitive factual accuracy index.
